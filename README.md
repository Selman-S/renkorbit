# RenkOrbit

**Renkli küreleri yörüngelerine yerleştir, galaksi yolculuğuna devam et!**

Mobil ve tablet odaklı web tabanlı renk sıralama bulmacası.

## Oynanış

Ana ekranda **Galaksi yolu** — 9 adımlık doğrusal ilerleme:

| Adım | İçerik |
|------|--------|
| 1–3 | 4 renk (Sıralı Rahat → Karışık Rahat → Karışık Süreli) |
| 4–6 | 8 renk (aynı desen) |
| 7–9 | 12 renk (aynı desen) |

Bir adımı tamamlayınca sonraki açılır. İlk açılışta oyuncu adı istenir.

## Kurulum

```bash
cd renkorbit
npm install
npm run dev
```

Production build: `npm run build`
